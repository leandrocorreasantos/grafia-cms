API REST completa com OpenAPI 3.0. Consuma o conteúdo de qualquer frontend: React, Next.js, Vue ou mobile.

Instalação Rápida

# Clone o repositório
$ git clone https://github.com/leandrocorreasantos/grafia-cms.git
$ cd grafia-cms

# Instale as dependências
$ npm install

# Inicie o banco de dados
$ docker compose up -d

# Execute as migrações e inicie
$ cd apps/api && npx prisma migrate dev
$ npm run dev
