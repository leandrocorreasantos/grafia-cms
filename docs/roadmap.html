Roadmap

Acompanhe o planejamento e o progresso do Grafia CMS.

v1.0 — Lançamento Inicial

Concluído 100%

Primeira versão estável com o core do CMS baseado em DDD e Clean Architecture.

  • ✅ Core DDD — Entidades, Value Objects, Repositórios
  • ✅ API REST com Express.js + TypeScript
  • ✅ Autenticação JWT + Application Passwords
  • ✅ Controle de Acesso por Cargos (RBAC)
  • ✅ CRUD de Posts e Usuários
  • ✅ Prisma ORM + PostgreSQL
  • ✅ Testes de Integração (98 testes)
  • ✅ Documentação da API (OpenAPI 3.0)

v1.1 — Temas & Editor

Em desenvolvimento ~60%

Sistema de temas visuais e editor de conteúdo WYSIWYG.

  • 🔧 Sistema de Temas com Theme Manager
  • 🔧 Editor de conteúdo (TipTap/ProseMirror)
  • 🔧 Upload de imagens e mídia
  • 🔧 Geração de slugs automática
  • 🔧 Páginas estáticas (sobre, contato)
  • 🔧 Modo rascunho e agendamento

v1.2 — Plugins & Webhooks

Planejado 0%

Sistema de plugins extensível e integrações via webhooks.

  • 📋 Sistema de Plugins (Plugin API + Hooks)
  • 📋 Webhooks para eventos do CMS
  • 📋 Cache com Redis
  • 📋 Filas de processamento (Bull/BullMQ)
  • 📋 Notificações por email
  • 📋 Exportação/Importação de dados

v2.0 — GraphQL & Multi-idioma

Planejado 0%

API GraphQL com suporte a múltiplos idiomas.

  • 📋 API GraphQL (Apollo/Relay)
  • 📋 Suporte multi-idioma (i18n)
  • 📋 Moderação de conteúdo
  • 📋 Analytics integrado
  • 📋 CLI para gerenciamento
  • 📋 SSO (OAuth 2.0 / SAML)
