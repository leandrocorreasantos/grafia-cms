Changelog

Histórico de todas as versões e alterações do Grafia CMS.

v0.1.0 Lançamento
15 de Junho de 2026
  • Core DDD com entidades User, Post, ApplicationPassword
  • API REST com Express.js + TypeScript
  • Autenticação JWT com suporte a Application Passwords
  • Controle de acesso baseado em cargos (RBAC)
  • CRUD completo de Posts e Usuários
  • Prisma ORM + PostgreSQL
  • Testes de integração (27 testes)
  • Testes unitários (71 testes)
  • Cobertura de testes: ~75%
  • Documentação da API com OpenAPI 3.0 + Redoc
  • Documentação do projeto (Roadmap, Changelog, Contributing)
v0.0.1 Primeiro Commit
1 de Junho de 2026
  • Inicialização do monorepo com Turborepo
  • Configuração do workspace apps/api e apps/web
  • Schema Prisma inicial (User e Post)
  • Estrutura DDD: domain, application, infrastructure, interfaces
  • Configuração Docker para PostgreSQL
